# أثر — A Piece of History

موسوعة عربية مفتوحة عن التاريخ الإسلامي، مبنية كواجهة ثابتة خفيفة تعمل بلا خادم، وتحمّل كل مقال عند الطلب لتناسب الاتصالات الضعيفة.

## البدء

يتطلب المشروع Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح العنوان الذي يعرضه Vite، ثم استخدم `#/` للتصفح.

## حالة المحتوى

يبدأ المستودع بفهرس مقالات فارغ عمدًا؛ لا توجد مقالات تجريبية ضمن نسخة المصدر المفتوح.
لإضافة مقال، انسخ القالب الموجود في `src/articles/_template.ts`، ثم أضف بياناته
واستدعاءه الكسول إلى `src/data/registry.ts`، أو استخدم محرر المقالات المحلي.

## محرر المقالات المحلي

لإنشاء مقال جديد من واجهة متصفح بدل تحرير الملفات يدويًا:

```bash
npm run article:editor
```

ثم افتح [http://127.0.0.1:4317](http://127.0.0.1:4317). يكتب المحرر ملف `src/articles/<slug>.ts` ويضيف الإدخال إلى `src/data/registry.ts`. الخادم محلي فقط، ولا يرفع المحتوى إلى أي خدمة خارجية. تحفظ المسودة تلقائيًا في `localStorage` داخل المتصفح.

يُحوّل المحرر التنسيق الغني إلى HTML دلالي خفيف داخل دالة `render()` تلقائيًا؛ لا تحتاج إلى كتابة HTML. استخدم أدوات العناوين `h2` و`h3` لبناء جدول المحتويات، وأدرج المصادر بصيغة `العنوان | https://example.com`، واستخدم أداة الصورة لإضافة رابط الصورة ووصفها البديل.

## الأوامر

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | تشغيل الموقع في وضع التطوير |
| `npm run build` | فحص TypeScript وبناء نسخة الإنتاج |
| `SITE_URL=https://example.com npm run build` | بناء النسخة مع توليد `sitemap.xml` و`robots.txt` بروابط الموقع الفعلية |
| `npm run sitemap` | توليد sitemap محليًا داخل `public/` عند الحاجة |

## النشر على Netlify

يستخدم المشروع إعداد `netlify.toml` للبناء تلقائيًا عبر `npm run build` ونشر مجلد
`dist`. قبل أول نشر، أضف متغير البيئة `SITE_URL` في إعدادات Netlify، مثل
`https://your-site.netlify.app`. سيولّد كل build ملفي `sitemap.xml` و`robots.txt`
داخل مجلد النشر باستخدام المقالات الموجودة في `src/data/registry.ts`.
| `npm run typecheck` | فحص الأنواع فقط |
| `npm test` | تشغيل اختبارات محرر المقالات باستخدام Node.js |
| `npm run article:editor` | تشغيل محرر المقالات المحلي |

## بنية المشروع

- `src/articles/` — وحدات المقالات lazy-loaded، ويحتوي افتراضيًا على القالب فقط.
- `src/data/registry.ts` — الفهرس الخفيف للمقالات.
- `src/components/` — مكونات الواجهة بدون إطار ثقيل.
- `scripts/article-editor.mjs` — خادم إنشاء المقالات المحلي.
- `scripts/article-editor.html` — واجهة المحرر والمعاينة.
