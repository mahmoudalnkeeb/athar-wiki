# Support

For usage questions and general project discussion, open a GitHub Discussion when Discussions are enabled. For a reproducible defect, use the [bug report template](https://github.com/mahmoudalnkeeb/athar-wiki/issues/new?template=bug_report.md). For a focused improvement, use the [feature request template](https://github.com/mahmoudalnkeeb/athar-wiki/issues/new?template=feature_request.md).

Before opening a request:

- Search existing issues and discussions.
- Include the project version or commit, browser and operating system when relevant.
- Include reproduction steps, expected behavior, and actual behavior.
- Keep sensitive information and security reports out of public issues. Follow [SECURITY.md](SECURITY.md) instead.

English and Arabic are welcome in issues and pull requests. Keep article and user-facing product content Arabic-first, as described in [CONTRIBUTING.md](CONTRIBUTING.md).
